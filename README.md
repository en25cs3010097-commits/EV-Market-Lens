# EV-Market-Lens
EV MarketLens explores electric vehicle market trends through interactive data visualizations. It analyzes vehicle categories, manufacturer sales, battery technologies, driving range, customer ratings, pricing, and sustainability metrics to uncover insights and support data-driven decisions.
